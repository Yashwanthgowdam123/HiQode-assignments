# Assignment – 8th August 2026

## Objective

Complete the following Ansible assignments.

---

## 1. Tomcat Deployment using Ansible

Create an Ansible playbook to deploy a Java WAR file in Apache Tomcat.

### Deployment Steps

- Stop the Tomcat service.
- Take a backup of the existing application (copy the existing WAR file to a backup folder).
- Deploy the new version of the WAR file.
- Start the Tomcat service.
- Verify the health of the newly deployed application.

---

## 2. Ansible Vault

Create an example demonstrating the creation and usage of **Ansible Vault**.

The demonstration should include:

- Creating an encrypted vault file.
- Editing the vault file.
- Viewing encrypted content.
- Using the vault file in an Ansible playbook.
- Executing the playbook with the vault password.

---

## 3. Dynamic Inventory

Create and demonstrate the usage of a **Dynamic Inventory** in Ansible.

The demonstration should include:

- Creating a dynamic inventory configuration.
- Discovering managed hosts dynamically.
- Verifying the generated inventory.
- Running an Ansible playbook using the dynamic inventory.
- Demonstrating host grouping and execution on selected groups.
